# whats360.live CRM and business integrations (dashboard features)

Documentation for the dashboard features that connect whats360.live to your own systems: **External Data Sources**, **Professional Embedding** (CRM inside your site), and **Persona** (AI assistant setup). These are configured in the dashboard. They are not public REST endpoints, so this folder documents the behavior shown on the dashboard pages and nothing more.

> Documentation derived from the whats360.live dashboard developer pages. The whats360.live owner states the documented endpoints are tested and working. **The examples in this folder were not executed against the live service by the person who wrote them.** Code is illustrative, uses placeholders only, and was not executed unless a test is listed. whats360.live links WhatsApp numbers by QR code. It is not the Meta Cloud API, not a Business Solution Provider, and not affiliated with or endorsed by Meta. No delivery or ban-avoidance guarantees.
