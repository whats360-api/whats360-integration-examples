# SMS Gateway in the whats360.live dashboard

Source: dashboard PDF export dated 2026-05-27, pages 29-32, read at full size for p29 and p30 and at thumbnail size for p31-32. Dashboard screens only. No SMS API endpoint is documented in the supplied materials. Not independently verified.

- Subscription page: two SMS plan tiers (a smaller one for small businesses, a larger one for growing companies). Both list devices, monthly message and campaign limits, and API access. Prices and limits are not published here, check the dashboard.
- New SMS campaign dialog: campaign name, message text with a character counter, recipient numbers (one per line, or upload an Excel/CSV file), and a SIM selector (the message is sent from a phone SIM).
- Outgoing SMS list and campaign statistics pages exist. In the export they were empty or showed zero counts.

This folder does not claim an SMS HTTP API. Ask support if you need one.

## Outgoing messages and overview (p31-32, read at full size, header dated 2026-05-07)
- Outgoing messages page: tracks the status of sent, queued and failed messages, with a status filter and refresh. The export shows it empty.
- SMS service overview: tiles for devices, campaigns, SMS sent and pending, a quick "new campaign" action, and an empty state saying to link an Android device through the VCash/SMS app to start sending. The export shows all counts at zero.
- Dashboard screens only. No SMS API was shown on these pages.
